# Typing is Learning
AI is changing how we code, but it shouldn't change how we learn. 👋 🌎 

When I was learning how to code, I would do a lot of interactive tutorials. I am a kit kid - I love a good "Hello World"s (where developer begin learning new coding frameworks) to get started and be like "whoa!" right away.

But who's still reading developer documents anymore?!

Hot (maybe not so hot) take:

As software engineers, typing IS learning. When we type, we are embodying the code, the software 

If we outsource our typing, we outsource our learning.
